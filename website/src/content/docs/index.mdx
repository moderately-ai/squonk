## Why squonk

<CardGrid stagger>
  <Card title="Dialects are data, not subclasses" icon="setting">
    A dialect is a small delta over a shared spec — inspect it, diff two
    presets field by field, or define a custom dialect without forking parser
    code. 14 built-in dialects ship today: ANSI, Postgres, MySQL, SQLite,
    DuckDB, BigQuery, Snowflake, Redshift, Databricks, ClickHouse, Hive,
    MSSQL, and more.
  </Card>
  <Card title="An AST built for tooling" icon="puzzle">
    Every node is owned, `'static`, and carries a byte span and a stable node
    ID. Trees can be stored, sent across threads, and mapped back to the exact
    source bytes — ideal for linters, formatters, and analysis.
  </Card>
  <Card title="Transpile between dialects" icon="random">
    Parse under one dialect and render under another in a single call. Produce
    canonical, fully-parenthesized, or PII-redacted SQL, or convert a query
    from one engine's syntax to another.
  </Card>
  <Card title="One core, three languages" icon="seti:html">
    Rust, Python, and TypeScript/WASM all parse SQL with the same
    implementation — no subtle differences between bindings, and the default
    Rust dependency tree is a single micro-crate.
  </Card>
</CardGrid>
